# MONTIS — Frontend на Vue 3

Учебный проект онлайн-записи на горнолыжном курорте. Клиентская часть реализована на **Vue 3 + TypeScript + Vue Router + Vite**. Backend — отдельный сервис (по архитектурной схеме Go + PostgreSQL).

## Запуск

Установите Node.js LTS. В папке проекта:

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Проверка сборки: `npm run build`.

## Подключение backend

Скопируйте `.env.example` в `.env` и при необходимости измените `VITE_PROXY_TARGET` (адрес Go-сервера). По умолчанию `/api` проксируется на `http://localhost:8000`.

Пока backend не запущен, каталоги и бронирования показывают ошибку подключения — это ожидаемо. Основные данные не хранятся в массивах frontend, а приходят из API. Список методов и предварительных форматов: `docs/API.md`.

## Структура

- `src/pages` — страницы: гость, клиент, инструктор, администратор
- `src/components` — переиспользуемые карточки
- `src/router` — маршруты Vue Router
- `src/stores/auth.ts` — простое состояние авторизации
- `src/api` — HTTP-клиент и запросы к backend
- `src/types` — TypeScript-типы данных
- `src/styles` — стили Montis
- `public` — изображения и иконки

## Границы ответственности

Frontend: интерфейс, навигация, формы, отображение данных, запросы к API и обработка ошибок. Backend: база данных, реальные права доступа, доступность интервалов, защита от двойного бронирования, уведомления и платежи.

## Текущее состояние

Это **упрощённая учебная Vue-версия** с основными экранами и подключением API. Сохранены общая визуальная палитра, фотографии, роли и ключевые сценарии. Это не полная пиксель-в-пиксель миграция всех исходных React-экранов: расширенные формы CRUD, перенос бронирования, платежи и уведомления ещё требуют разработки и интеграции. Доступ к страницам по ролям на клиенте — только удобство интерфейса; безопасность обеспечивает сервер.
